# Ecommerce-Sales-Analysis-Dashboard

Headline:
Built an end-to-end Excel dashboard to analyze e-commerce sales data with KPIs, charts, pivot tables, and interactive filters for business decision-making.

Short Description:
This project analyzes e-commerce sales data using Microsoft Excel to create an interactive dashboard that tracks sales performance, revenue trends, product categories, and customer purchasing behavior through data visualization.

Purpose of the Project:
The purpose of this project is to convert raw e-commerce sales data into meaningful insights using Excel dashboards, helping users monitor key business metrics, identify sales trends, and support data-driven decision-making.

Tech Stack Used:
Microsoft Excel — Main tool used to build the dashboard and analyze data
Pivot Tables — To summarize and explore sales data quickly
Pivot Charts — To visualize trends and comparisons
Excel Formulas & Functions — For calculations and KPI metrics (SUMIFS, COUNTIFS, IF, VLOOKUP/XLOOKUP)
Conditional Formatting — To highlight important insights and trends
Slicers & Filters — For interactive dashboard navigation
Data Cleaning & Preprocessing — Removing duplicates, formatting, and preparing raw data
KPI Cards & Charts — Revenue, orders, profit, customer metrics, and product performance
CSV / Excel Dataset — Source data for sales analysis
